# 📥 EXPORT SETTINGS CANVA

### Pour Instagram Posts (1080x1080)
- Format : PNG ou JPG
- Quality : High (1080px)
- Background : Transparent (if needed)

### Pour Affiches (Impression)
- Format : PDF
- DPI : 300 dpi (important!)
- Size : 2480x3508 (A4) ou 3508x4961 (A3)
- Color mode : CMYK (if printing)

### Pour Réseaux Sociaux (web)
- Format : PNG ou JPG
- Quality : Medium-High (1200px max)
- Taille fichier : < 5MB

### Pour Reels/Videos
- Format : MP4
- Resolution : 1080p
- Frame rate : 30fps
- Duration : 15-30 sec
